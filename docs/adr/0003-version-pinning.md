# ADR 0003: Version pinning

Date: 2026-10-16 · Status: accepted

## Decision

| Component | Version | Source |
| :--- | :--- | :--- |
| Java | 25 (LTS), Eclipse Temurin | Spring Initializr options, 2026-10-16 |
| Spring Boot | 4.1.1 | Initializr default (latest GA) on 2026-10-16 |
| Maven | 3.10.0 via Maven wrapper 3.3.4 | Generated by Initializr |
| PostgreSQL | 18 (`postgres:18-alpine`) | Same image in dev, tests and production |
| Caddy | 2 (`caddy:2`) | |
| Bootstrap | 5.3.8 (WebJar `org.webjars.npm:bootstrap`, served by the app, no CDN) | Added in M3, 2026-10-17 |

## Consequences

- Use `mvnw.cmd` on Windows and `./mvnw` on Linux/CI; no global Maven needed.
- Upgrade Spring Boot patch releases regularly; review minor upgrades with this ADR.
